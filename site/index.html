Fast triangulation of polygons (simple and with holes).

Simple polygons. Interior holes. No added points.

Triage combines three algorithms to handle small polygons and large geographic boundaries.

Explore the code ↗

Stencil lettering keeps each hole simple. Only original boundary vertices are used. Reproduce this figure ↗

Triage draws on ideas from theoretical computational geometry, including monotone chains and implicit vertical decomposition, whose practical benefits emerge on sufficiently large inputs. Such polygons arise in GIS applications, for example in detailed country, state, and county boundaries.

01 / THE ALGORITHM

Three paths.
One triangulator.

01

Small polygons

Up to 64 vertices, without holes: ear cutting with a compact mask of live reflex vertices.

02

Small domains with holes

Up to 32 total vertices: join a hole when it blocks an ear, then continue cutting.

03

Larger inputs

Sweep monotone chains, insert diagonals between original vertices, and triangulate compact boundary ranges.

03 / GET STARTED

Two implementations.
The same geometry.

C++17

Header-only · Boost headers
#include <triage/triage.hpp>

std::vector<triage::Point> points{
    {0,0}, {4,0}, {5,4}, {1,5},
    {1.5,1}, {2,2}, {3,1}
};
auto mesh = triage::triangulate(
    points, {0,4,7});

Zero-based indices. Flat coordinate storage.

Julia

Native Julia · no runtime dependencies
using Triage

points = Point[
    (0,0), (4,0), (5,4), (1,5),
    (1.5,1), (2,2), (3,1)
]
triangles = triangulate(
    points, [1,5,8])

One-based indices. Inline coordinate tuples.

04 / CHECKS & SCOPE

Vibe programming.
Explicit verification.

Created using Codex, with the algorithms, tests, scripts, and measurements available for inspection.

117,415 prepared domains. C++ and Julia output the same triangles, byte for byte. Independent exact-arithmetic checks certify orientation and boundary coverage. ASan/UBSan passed 118,708 generated and corpus cases.

Input assumptions matter. Triage expects simple boundaries and disjoint interior holes. The current chain path requires distinct x coordinates. It does not implement Earcut’s malformed-input recovery, and adversarial inputs can incur quadratic work.
